## 🚀 How to Get Started

### 1. Read Documentation (3 min)
👉 **Open: [`START_HERE.md`](START_HERE.md)**

### 2. Create Supabase Project (5 min)
- Go to https://supabase.com
- Create new project
- Get API credentials

### 3. Configure Environment (2 min)
Create `.env` file:
```
VITE_SUPABASE_URL=https://your-project.supabase.co
VITE_SUPABASE_ANON_KEY=your-key-here
VITE_TCGDEX_API_URL=https://api.tcgdex.net/v1
```

### 4. Setup Database (2 min)
Copy `SETUP_DATABASE.sql` to Supabase SQL Editor and run

### 5. Start Development (1 min)
```bash
npm run dev
# Visit http://localhost:5173
```

### 6. Test Features (5 min)
- Add products in admin panel
- View in catalog
- Test cart, search, filters
